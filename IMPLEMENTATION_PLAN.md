# План MVP SockLock Hook Variations

## Що перевіряємо

Чи може motion-дизайнер за один пакетний запуск отримати кілька готових варіацій одного рекламного ролика, де змінюється лише вступний напис. MVP перевіряє швидкість складання й експорту. Результат рекламного тесту оцінюється окремо.

## Межі реалізації

- Локальний Node.js CLI. Вхід — готовий вертикальний MP4 та UTF-8 CSV із заголовком `id,hook`. Вихід — окремий H.264 MP4 для кожного валідного рядка.
- Змінюємо один чинник. Текстовий hook накладається лише протягом перших 3 секунд. Відеоряд, загальна тривалість і звук вихідника зберігаються.
- Три короткі англомовні hooks у демо, три вихідні файли, окремий CSV із четвертим задовгим hook. Ліміт довжини має відповідати місцю для тексту. Задовгий рядок пропускається з поясненням, решта експортується.
- Синтетичний базовий ролик SockLock на 10–15 секунд і його hooks явно позначити в README та іменах прикладів. Локальне демо працює без ключів та без завантаження матеріалів.
- Встановлений FFmpeg має `overlay`, PNG decoder і `libx264`, але не має `drawtext`. Рендерити прозорий PNG з текстом через короткий Python/Pillow helper і накладати його FFmpeg за інтервалом часу. Документувати системні вимоги й змінну шляху до Python, якщо потрібна.
- Перевіряти формат CSV, унікальність і безпечність імен варіацій, базовий відеофайл. Викликати процеси аргументами без shell. Повідомляти, що зроблено, що пропущено і куди збережено файли. Рендер виконувати послідовно для простого дебагу.

## Послідовність

1. Створити синтетичний базовий кліп, CSV та граничний приклад.
2. Реалізувати валідацію вводу, підготовку PNG і пакетний рендер.
3. Запустити демо. Перевірити три читабельні hooks, однаковий кадр після вступу й коректну тривалість. Запустити сценарій із задовгим текстом.
4. Написати короткий README українською з однією командою для швидкого старту, прикладом CSV, очікуваними файлами та поясненням коду. Додати короткі кроки для демонстрації.
5. Окремо повторити запуск із розпакованого архіву.

## Критерій готовності

У чистій папці можна запустити демо, отримати три відтворювані MP4, побачити, що різниця обмежена вступом, і показати, як інструмент обробляє задовгий hook. На реальних матеріалах наступний крок — порівняти активний час дизайнера на партію з трьох готових варіацій вручну та через CLI, включно з рев’ю.
